# GIT-001 — ordinary issue response violates its Swagger contract

Severity: Medium. Status: confirmed, not filed. Impact: strict API clients reject a successful ordinary-issue response; no data loss or auth bypass is alleged.

Environment: unmodified Gitea 28.2.0 Docker image, SQLite, Windows local and Ubuntu CI, requests/Schemathesis 3.39.16. [Exact image digest](../evidence/environment.json).

Precondition: public `qaowner/journeys` repository with Seed issue, no associated PR, assignee or milestone.

1. GET `/swagger.v1.json`.
2. GET `/api/v1/repos/qaowner/journeys/issues`.
3. Validate the 200 JSON response against the served GET response schema.

Expected: the documented model permits the absent association values emitted for an ordinary issue, or the response uses a contract-compliant representation.

Actual: `"pull_request": null` fails because `PullRequestMeta` declares `type: object` without nullability. Schemathesis reports `None is not of type 'object'` at `/items/properties/pull_request`. Other absent pointer fields need consistent treatment; these are one contract defect class.

Evidence: [captured response/schema](../evidence/issue-contract.json), [API JUnit](../evidence/api-junit.xml), `test_contract[/repos/qaowner/journeys/issues]`. Reproduced locally and in [corrected CI](https://github.com/iamnajib71/qa-automation/actions/runs/39808735895). Corrected API suite: 13 passed, this check failed. Initial Schemathesis auth-inference failures were framework errors and are excluded from this report.

Duplicate check: `swagger null`, `pull_request schema`, `null API`, null issue titles and nullable PR searches found no matching report. [Generator replacement proposal](https://github.com/go-gitea/gitea/issues/33685) is related tooling work. [Search evidence](upstream-search.md).

Prepared fix: generate nullable pointer schemas, preserve nullable references during OpenAPI conversion and regenerate both contract documents. [Source branch, patch and before/after regression proof](../fixes/README.md). No upstream PR was opened.
