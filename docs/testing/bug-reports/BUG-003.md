# BUG-003: Unknown project is presented as an existing unscanned workspace

Status: fixed and covered by permanent regression. Severity: Medium. Priority: P2. Reporter/owner: Nazmul Hassan.

Environment: Windows, Node 22.22.0, Next.js development server at http://127.0.0.1:4173. Reproduced against original revision 5f1610f before any fix was applied. Synthetic input only.

## Steps

1. Start the original portal on port 4173.
2. GET /projects/00000000-0000-4000-8000-000000000000 in a browser or HTTP client.
3. Inspect the HTTP status and response body.

Expected: HTTP 404; unknown workspace is not represented as an existing project.

Actual: HTTP 200 and text: "Project not scanned yet" / "This workspace exists".

Impact: incorrect error/existence handling misleads users and API clients, and makes release monitoring less reliable.

Root cause: An empty scan history was used as the existence test; missing and unscanned projects were conflated.
