# BUG-002: Malformed URL bypasses validation and returns 500

Status: fixed and covered by permanent regression. Severity: Medium. Priority: P1. Reporter/owner: Nazmul Hassan.

Environment: Windows, Node 22.22.0, Next.js development server at http://127.0.0.1:4173. Reproduced against original revision 5f1610f before any fix was applied. Synthetic input only.

## Steps

1. Start the original portal on port 4173.
2. POST /api/smoke-test with body {"websiteUrl":"http://["}.
3. Inspect the HTTP status and response body.

Expected: HTTP 400 for invalid input; no scan/project should be created.

Actual: HTTP 500: {"error":"Invalid URL"}.

Impact: incorrect error/existence handling misleads users and API clients, and makes release monitoring less reliable.

Root cause: The API validated only string length; URL parsing threw during service execution.
